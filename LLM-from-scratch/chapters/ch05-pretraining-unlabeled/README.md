# 第5章：在无标签数据上进行预训练 / Chapter 5: Pretraining on Unlabeled Data

## 概览 / Summary
· 本章讲清楚“预训练”在做什么：用大量无标签文本，让模型学会预测下一个 token。  
· 重点覆盖训练目标、损失函数、训练循环、数据批处理，以及生成解码与模型保存的基础流程。  

## 学习目标 / Learning Outcomes
· 能把“下一个 token 预测”写成可训练的输入-目标形式，并用交叉熵损失进行优化。  
· 能理解训练与生成的关键控制点，包括解码策略与检查点保存。  

## 关键内容 / Key Topics
· 训练前的模型状态：随机初始化权重与“无语言知识”的输出表现。  
· 训练目标：输入序列与目标序列错位（右移一位）的自回归学习设置。  
· 交叉熵损失：关注目标 token 的概率，并用负对数似然度量错误程度。  
· 训练循环：前向传播、计算损失、反向传播、参数更新。  
· Batch 与上下文窗口：用滑动窗口切片，再堆叠成批次提升吞吐。  
· 损失曲线解读：训练损失与验证损失的分叉，以及过拟合信号。  
· 生成解码：greedy 与概率采样的差异与适用场景。  
· 温度（temperature）：调节分布尖锐程度，影响稳定性与多样性。  
· Top-k 采样：限制候选集合，增加可控性并降低离谱输出风险。  
· 模型保存：state_dict 与 checkpoint（.pth），用于续训与推理复用。  
· 使用预训练权重：对齐架构后加载 GPT-2 等权重，避免从零训练的高成本。  

## 运行提示 / Notes
· 训练阶段建议同时记录训练集与验证集指标，用于及时发现过拟合。  
· 生成阶段建议先用 greedy 跑通流程，再逐步加入 temperature 与 top-k 做对比。  
· 保存 checkpoint 的频率与命名规则需要固定，便于中断恢复与结果复现实验。
