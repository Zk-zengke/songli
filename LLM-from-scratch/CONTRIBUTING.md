## 工作流
1. 对重要变更先提出 Issue 或 Discussion。
2. 按 `chapters/README.md` 的结构组织章节。
3. 统一命名（`chNN-short-title`）。
4. 新增或改名章节后同步更新 `chapters.yml`。

## 内容规范
- 教程尽量步骤化、可复现。
- 外部数据或素材请在章节 README 中链接说明。
- 章节内容保持短小清晰。
