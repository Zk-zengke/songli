# 第3章：注意力机制 / Chapter 3: Attention Mechanism

## 概览 / Summary
· 从 RNN 在长序列上的“记忆瓶颈”出发，引出注意力机制为何能改进序列建模。  
· 重点讲清自注意力如何把“词向量”变成“带上下文的词向量”，并给出从打分到加权融合的完整计算链路。  
· 章节进一步扩展到生成场景所需的因果注意力（mask）与多头注意力的设计动机。  

## 学习目标 / Learning Outcomes
· 理解自注意力的核心计算流程，并能解释每一步在做什么。  
· 理解因果 mask 与多头注意力在 Transformer 中的作用。  

## 关键内容 / Key Topics
· 背景：RNN 编码器把整句压缩到固定向量带来的信息瓶颈。  
· 注意力直觉：生成时可动态“回看”输入的关键位置并分配权重。  
· 自注意力目标：得到 context-aware embedding，让每个词包含上下文信息。  
· Q/K/V：用可学习投影把输入映射为 Query、Key、Value。  
· 相关性计算：用点积得到注意力分数（attention scores）。  
· Softmax 归一化：把分数变成可解释的权重分布（attention weights）。  
· 上下文向量：用权重对 Value 加权求和，得到输出表示。  
· 因果注意力：禁止看到未来 token，保证从左到右生成。  
· Mask 实现：在 Softmax 前把未来位置置为 -inf，使其权重归零。  
· 多头注意力：并行多个注意力头，从不同“视角”建模关系后再融合。  

## 运行提示 / Notes
· 通常会在代码中显式实现 Q/K/V 投影、注意力打分、Softmax、加权求和与 mask 逻辑。  
· 建议先跑通单头自注意力，再加入因果 mask，最后再扩展到多头结构，便于逐步验证张量形状与数值行为。
