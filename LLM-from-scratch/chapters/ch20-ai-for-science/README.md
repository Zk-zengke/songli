# 第20章：AI for Science / Chapter 20: AI for Science

## 概览 / Summary
· 本章给出 AI for Science 的概念框架：将机器学习/深度学习作为“科研加速器”，嵌入科研与工程研发的关键环节。  
· 内容以“加速科研闭环”为主线，覆盖从数据与假设到预测、设计、验证与迭代的整体路径。  
· 本章为概念性综述章节，无配套教学代码，了解框架与典型任务类型即可。  


## 关键内容 / Key Topics
· AI4S 的定位：不是替代科研写作，而是提升提出假设、预测筛选、实验设计与仿真扫描的效率。  
· 兴起原因：数据规模与类型增长、算力门槛下降、模型表征更通用且可迁移。  
· 预测型任务：将“结构/条件 → 性质/结果”建模为可学习映射，用便宜预测替代昂贵实验/仿真以缩小搜索空间。  
· 输入形态：分子结构（SMILES/分子图/3D 构象）、材料配方与工艺条件、显微图像与谱图、时间序列信号等。  
· 输出指标：性质参数、功能表现/活性、稳定性与寿命、工程指标（产率、纯度、缺陷率）等。  
· 生成与设计型任务：在约束下主动提出候选（新分子/新材料结构、蛋白或核酸序列、实验条件组合），形成“生成—评估—再生成”的优化循环。  
· 因果与机理型任务：从相关性走向可验证机制，强调对照、干预、反事实与可解释中间表征，以支持可靠决策与实验设计。  
· 科学数据特点：规模更小、成本更高、结构化噪声与分布偏移更强，预处理需统一单位与条件，并采用更严格的切分与不确定性记录。  
· 表征与模型选择：序列常用 Transformer，图结构常用 GNN，图像常用 CNN/ViT，多模态任务强调对齐与融合。  
· 自动化闭环：以“决策与设计—自动执行—数据回流—模型更新再迭代”实现高信息量、低试错成本的持续优化。
