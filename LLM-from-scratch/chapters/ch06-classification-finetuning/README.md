# 第6章：针对分类任务的微调 / Chapter 6: Finetuning for Text Classification

## 概览 / Summary
· 本章以短信垃圾识别为例，讲清如何把“预训练的生成模型”改造成“监督分类模型”，并完成端到端微调与推理。  
· 重点包含数据准备与对齐（类别平衡、padding、mask）、模型结构改造（加分类头）、训练策略（冻结与逐步解冻）以及预测与训练曲线解读。  

## 学习目标 / Learning Outcomes
· 能将预训练 GPT 接入分类头，完成垃圾短信二分类的微调与推理。  
· 能理解并应用数据平衡、padding/mask、冻结/解冻与最后一个 token 表示等关键做法。  

## 关键内容 / Key Topics
· 微调类型对比：指令微调与分类微调的输入输出形式差异。  
· 数据集与类别平衡：处理 ham/spam 数量不均，避免模型“总猜多数类”。  
· Padding 与 attention mask：对齐 batch 内序列长度，忽略填充位置，保证学习信号干净。  
· 批处理格式：文本→token ID→定长矩阵，与标签数组一起组成可并行训练的数据批。  
· 添加分类头：用分类输出替换“预测下一个 token”的词表投影层，把生成模型改为分类模型。  
· 冻结与解冻：先训分类头再逐步解冻上层，用更小学习率继续适配任务分布。  
· 为什么选最后一个 token：在因果注意力下汇总全句信息，用作句级表示进行分类。  
· 从 logits 到标签：用 argmax 从类别分数中选出最终预测类别（softmax 可选）。  
· 训练监控：结合损失与准确率曲线判断收敛、泛化与过拟合风险。  

## 运行提示 / Notes
· 关键实现点通常集中在：数据对齐（padding/mask）、模型 head 替换、冻结/解冻训练日程与推理函数封装。  
· 建议先用“只训练分类头”跑通，再加入逐步解冻与学习率调整，便于稳定复现结果与定位问题。
